# Рабочая стена

Скрипт для автоматического запуска рабочих приложений.

## Приложения для установки на новом рабочем месте

- **Notepad++** — текстовый редактор (дистрибутив на яндекс диске, рабочие файлы в C:\Users\smirn\OneDrive\notepad++)
- **mRemoteNG** — управление удалёнными подключениями (дистрибутив на яндекс диске, конфиги в C:\Users\smirn\OneDrive\mRemouteNg, укажи этот путь)
- **Google Chrome** — браузер
- **Microsoft Office (Outlook)** — почта и документы (дистрибутив на яндекс диске)
- **Dion** — корпоративный мессенджер (дистрибутив на яндекс диске)
- **Telegram Desktop** — мессенджер
- **Handy computers** — голосовой ввод. Модель Whisper Large, постобработка локальной qwen3.5
- **LM Studio** — работа с локальными LLM
- **OpenCode или VS Code + Kilo code** - IDE с агентами
